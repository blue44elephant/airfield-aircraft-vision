# RarePlanes-derived experiment material

The experiment manifest includes transformed RarePlanes aircraft boxes and source metadata.
The image examples contain separate annotation/detection overlays on RarePlanes imagery.
These dataset-derived materials retain CC BY-SA 4.0; they are separate from the repository's code license.

RarePlanes Dataset, June 2020. J. Shermeyer, T. Hossler, A. Van Etten, D. Hogan, R. Lewis, D. Kim.
In-Q-Tel / CosmiQ Works and AI.Reverie.
https://www.iqt.org/library/the-rareplanes-dataset
https://creativecommons.org/licenses/by-sa/4.0/

Changes: bounded subset selection, conversion of COCO XYWH to XYXY boxes, grouping/split manifests,
experimental model detections and visual overlays. Original imagery is not changed.
